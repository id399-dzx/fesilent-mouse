# Fesilent Mouse v0.2.3 预览版

新增布局方案、修复精密滚动的小幅位移丢失，并完善 Mac 授权恢复引导。

## 更新内容

- **布局方案**：以“办公室”“书房”等名称保存、更新、恢复或删除设备方位、偏移和连接目标。恢复使用最新地址，已移除的设备不会重新加入；传输过程中禁止应用方案。
- **精密滚动**：保留倍率调整后的小数，系统输入边界按轴累计余量，修复慢滑被逐帧取整吞掉；换向、切换模式、释放输入时清理旧余量。普通滚轮保持原有行为。
- **Mac 授权提示**：实时检测辅助功能信任；系统已就绪时提供重新连接，权限异常时提供恢复说明。打包支持固定证书/团队及正式签名、公证门禁。
- 保留单实例工作台、自动显示本机IP和端口、已保存设备管理、剪贴板及文件复制粘贴等功能。

## 下载

- **Windows x64**：`fesilent-mouse.exe`，免安装运行。
- **Apple Silicon Mac**：`fesilent-mouse-macOS-arm64.zip`，解压后将 App 放入“应用程序”。Intel Mac 与 Linux 暂无本次安装包。
- `SHA256SUMS` 可核对两个包的传输完整性。

这是预览发布：Windows未作Authenticode签名，公开Mac包为ad-hoc签名、未经Apple公证。正式分发检查工具已经加入源码，不代表本预览包拥有Developer ID或已公证。Mac辅助功能仍须用户本人授权；公开包签名身份更新可能需要重新授权，软件不会自行重置系统权限。

## 验证范围

Rust工作区293项通过、0失败、9项既有忽略；36项打包脚本测试通过。Mac与Windows严格Clippy、release编译、包结构/版本/SHA验证通过。默认分支另修复Windows自动打包的中文控制台编码问题，不改变应用程序或包校验规则。布局保存/恢复/删除已通过隔离原生窗口验证。Windows实际操作、双机触控板/滚轮手感等项目仍待真机验收。

当前仍**每次一台活动连接**；“我的设备”和“布局方案”可以保存多台电脑，不代表多台同时在线。原生跨屏文件拖拽、完整多指手势、Windows UAC安全桌面/登录及Mac锁屏控制尚未提供。

旧版发布和用户配置/配对数据保留。
