# Fesilent Mouse 0.2.0 界面改进

本 Fork 根据用户 2026-10-19 的请求创建，目标是让 Windows 与 Mac 局域网键鼠共享工具更易配置、更易看清连接状态。

## 使用场景与视觉

软件仍使用 Rust、egui 与原生系统托盘。主窗口采用浅色画布、清晰的文字层级和克制的蓝色强调，避免原版深色卡片在浅色主题下的低对比文字。主操作与当前连接状态放在顶部；连接与设备、键鼠设置、传输和剪贴板、关于与诊断按用途组织。窗口可调整大小，内容应能滚动，长历史记录不会将底部操作挤出可用区域。

## 连接交互

- 自动发现与手动连接是明确选项。手动输入裸 IP 时自动补上 UDP 53728。
- 地址先校验，再应用；输入尚未完成时不应反复重连。
- 运行中应用新地址时，停止旧会话并等待退出，然后启动新会话，避免监听端口冲突。
- 显示真实连接状态与最近错误，不用空白界面掩盖地址错误或连接超时。
- 告知用户：Windows 可填 Mac 的地址，Mac 端留空并启用互控；两端都主动连接时不能互相监听。
- Mac 的辅助功能授权要求继续保留。设备方位与推向屏幕边缘的操作提示应当可见。

## 品牌与兼容

显示名为 Fesilent Mouse，可执行文件名为 fesilent-mouse，版本为 0.2.0。配置、身份、日志、开机自启与接收目录使用 FesilentMouse，避免修改原 MouseShare 的设置和身份文件。现有配置不会静默复制；首次运行需要重新配置并配对。

为保持与上游设备通信的可能性，协议版本、消息编号、UDP 53728 和 mDNS 服务类型继续沿用上游。跨版本、跨设备实际互控仍需要两端真机验证，构建成功不能替代该验证。

## 验证与交付

CI 在 Windows 与 Apple Silicon macOS 上执行格式检查、Clippy、工作区测试和 release 构建，保留可下载工件及 SHA-256。Windows 工件另外在本机启动并检查设置界面。Mac 的系统辅助功能授权与双机手感验收需要设备使用者完成，验证记录必须区分自动化结果与实际双机体验。
