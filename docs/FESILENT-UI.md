# Fesilent Mouse 0.2.0 界面改进

本 Fork 根据用户 2026-10-19 的请求创建，目标是让 Windows 与 Mac 局域网键鼠共享工具更易配置、更易看清连接状态。

## 使用场景与视觉

软件仍使用 Rust、egui 与原生系统托盘。2026-10-19 的第二轮优化采用用户确认的设备工作台布局，视觉参考 [Fesilent 科研数据工作台](https://fesilent.com/data-processing)。

- 背景 `#f8f7f9`、正文 `#211f27`、次要文字 `#77747f`、细描边 `#e7e3e9`、紫色细节 `#755bc6`、近黑主按钮 `#1d1c22`。
- 白色大圆角面板配柔和粉、紫、蓝光晕。光晕由 egui 顶点颜色绘制，不引入位图或 WebView。
- 导航为「工作空间 / 共享记录 / 使用偏好 / 关于与诊断」，宽窗口使用侧栏，窄窗口使用顶部导航。设备排列和当前连接状态在首页直接可见。
- 控制端可拖动对端屏幕向四个方向吸附，保留方向按钮；Mac 默认接收控制，也可显式开启主控。布局、穿越边缘与已选设备配置同步保存。
- 长历史可滚动，活跃传输使用底部入口，避免在所有页面顶部插入整张传输卡。

「我的设备」支持保存多台设备、选择一个活动目标、按设备配置方位和沿边偏移。0保持原比例映射，非零按物理像素计算，只有共同边能跨越。仍不提供任意坐标拖拽、多路同时控制或各物理显示器分别编排。

## 连接交互

- 自动发现与手动连接是明确选项。手动输入裸 IP 时自动补上 UDP 53728。
- 地址先校验，再应用；输入尚未完成时不应反复重连。
- 运行中应用新地址时，停止旧会话并等待退出，然后启动新会话，避免监听端口冲突。
- 显示真实连接状态与最近错误，不用空白界面掩盖地址错误或连接超时。
- 告知用户：Windows 可填 Mac 的地址，Mac 端留空并启用互控；两端都主动连接时不能互相监听。
- Mac 的辅助功能授权要求继续保留。设备方位与推向屏幕边缘的操作提示应当可见。
- 明确区分搜索、监听等待、连接、核对配对码、已连接、重连、权限未就绪与失败，控制目标直接读取引擎状态。
- 首次图形界面配对需两端核对同一条 TLS 会话生成的六位码，明确确认后才保存信任。拒绝或 90 秒超时会停止本轮连接，用户可主动重试；命令行调试保留原有 TOFU 行为。
- 解除配对先停止并等待后台会话退出，再清理本应用的 `trust.json`；不删除证书身份。重新配对时须在两台电脑上都先忘记设备，再连接并核对六位码；只忘记一端时，另一端仍沿用原信任记录，不会显示配对码。
- 「暂停连接」会停止互控、剪贴板及当前连接内的传输。「暂时锁在本机」只结束当前控制关系并拒绝跨屏，连接与传输仍可保持；临时锁定在断开后复位。

## 使用偏好与共享

切换手感提供轻触、标准、防误触预设，保留进入与返回推挤距离的独立调整。启用Mac主控后也提供控制端设置。滚轮倍率为1.0–3.0倍，与方向反转独立；修饰键映射在接收端生效。默认Ctrl+Alt+空格切换/返回，Ctrl+Alt+L临时锁定/解锁，可更改修饰键组合与末键。设置保存后显示短时反馈。

共享记录保留大文件确认、取消、速率和历史。失败原因以可操作的提示进入当前条目及内存历史，取消和完成的终态不会被迟到的错误覆盖。接收完成后可打开默认接收目录。剪贴板历史的「回填」更名为「复制到本机」；历史仍仅驻留内存。

## 品牌与兼容

显示名为 Fesilent Mouse，可执行文件名为 fesilent-mouse，版本为 0.2.0。配置、身份、日志、开机自启与接收目录使用 FesilentMouse，避免修改原 MouseShare 的设置和身份文件。现有配置不会静默复制；首次运行需要重新配置并配对。

为保持与上游设备通信的可能性，协议版本、消息编号、UDP 53728 和 mDNS 服务类型继续沿用上游。跨版本、跨设备实际互控仍需要两端真机验证，构建成功不能替代该验证。

## 验证与交付

CI 配置在 Windows 与 Apple Silicon macOS 上执行格式检查、Clippy、工作区测试和 release 构建，保留可下载工件及 SHA-256。本轮本机只交叉编译 Windows 和检查其界面分支，尚未在 Windows 真机运行。Mac 的辅助功能授权与双机手感验收需要设备使用者完成，验证记录须区分自动化结果与双机体验。

原项目来源与权利说明见仓库根目录 NOTICE.md。上游历史设计文档继续保留；本文件和 SPEC 的 Fork 补充说明描述当前分支的差异。

## 隔离界面预览

开发时可设置 `FESILENT_UI_PREVIEW=windows` 或 `mac`，使用纯内存配置显示对应平台的界面。该模式在主入口优先处理，禁止启动真实连接、自检、录制或输入捕获，不保存用户配置、不改启动项或配对记录，也不初始化文件日志。正常开发运行仍需传 `--log-dir ./logs` 将日志留在项目中。`FESILENT_UI_PREVIEW_STATE=connected` 或 `reconnecting` 仅用于构造预览状态，不能作为双机验证结果。

预览仅供开发验证，发布版的正常启动不设置上述环境变量。实际辅助功能授权、跨机输入及系统文件管理器行为仍需真机回归。
