# 设备布局方案（F-1021）

2026-11-09，已实现首批布局预设。工作空间下方新增“布局方案”，沿用白色卡片、灰紫背景和现有按钮样式。

## 使用

1. 在“我的设备”里配对电脑、设置四向位置和沿边偏移，并选择连接目标。
2. 输入“办公室”“书房”等名称，点击“保存当前布局”。最多20项，名称1–40字符，同名不会静默覆盖。
3. 点击对应方案“应用布局”，恢复其设备位置与连接目标。原先已启用时，先安全结束旧会话，再连接恢复后的目标；原先暂停时保持暂停。
4. “更新为当前布局”显式替换对应快照；“删除…”二次确认，仅删除方案，设备与配对保留。

传输或撤销设备期间禁止应用、更新/保存和删除。方案不保存旧IP、设备别名、主控/剪贴板偏好或信任文件。恢复使用当前已保存设备的最新地址，不会新增已移除设备；如果原目标已移除，则清除目标并保持暂停。新增电脑保留原位，与预设方向冲突时整体拒绝，原配置不变。

这是本机**设备**布局预设，仍一次一台活动连接。它没有提供逐显示器自由画布或多个设备同时在线。仅恢复本机配置，另一端配置不自动同步。
