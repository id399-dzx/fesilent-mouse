Fesilent Mouse v0.2.2 改进重复启动和连接设置体验。

- **一个工作台管理设备**：重复双击或运行其他目录的程序副本，会恢复已有窗口；多台电脑统一在“我的设备”添加和选择，每次连接一台。
- **自动显示本机地址**：工作台直接显示本机局域网 IPv4 与监听端口，支持一键复制，换网后自动刷新。
- **自动补齐端口**：输入裸 IP 或 `IP:` 时默认补为 `53728`，显式填写的有效端口保持不变；修复 GUI 丢失自定义监听端口的问题。
- **恢复已有窗口**：处理 Windows 前台激活及 Mac Finder/Dock 重开，覆盖启动竞争、崩溃恢复和退出期间重开的情况。

下载与运行：

- Windows x64：下载 `fesilent-mouse.exe`，免安装运行。
- Apple Silicon Mac：下载 `fesilent-mouse-macOS-arm64.zip`，解压后运行 `.app`。
- `SHA256SUMS` 可校验两平台下载包的完整性。

延续 v0.2.1 的黑白图标、跨屏键鼠、双向剪贴板、复制粘贴文件传输和设备管理；协议及数据目录保持一致。

已通过 277 项工作区测试、严格 Clippy、双平台 release 构建、包结构与校验和检查，并在 Mac 上验证重复启动、Finder 重开和地址复制。Windows 实际前台焦点、网卡枚举和双机互控仍需真机确认。

此版本仍为预览版。Windows EXE 未做 Authenticode 签名；Mac 为 ad-hoc 签名，尚未 Apple 公证，需授予辅助功能权限。旧版本保留在 Releases。
