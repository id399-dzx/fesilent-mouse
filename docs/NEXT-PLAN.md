## 2. 可新增功能（建议清单，采纳后登记 TASKS.md）

### A. 已立项/有设计的

| 功能 | 依据 | 说明与执行方式 |
|---|---|---|
| **拖拽文件穿越传输**（T-508） | 你 2026-06-20 指定的目标，设计文档已写好（docs/FEATURE-drag-transfer.md，含 T-508a~f 子任务拆分） | 唯一"设计完成待实现"的大功能。A 机拖住文件穿越边缘→B 机松手落到光标处，与粘贴式共存。建议放在 v1.0 发布后作 v1.1 头牌，避免在稳定性验收前引入新的平台层风险面 |

### B. Roadmap 既定方向（REQUIREMENTS §7）

| 版本 | 功能 | 价值/难点 |
|---|---|---|
| v1.1 | 文件断点续传（FR-503 P2 项） | 大文件弱网友好；协议加 offset 续传即可，风险低 |
| v1.1 | 键盘布局感知映射 | 解除"两端必须同为 QWERTY"限制（现只做了不一致警告 T-307）；映射表工作量大但纯逻辑、可单测 |
| v1.2 | 3 台及以上设备组网 + 任意网格屏幕布局 | 架构影响大（状态机/发现/信任列表都要多对多化），需先出设计文档评审 |
| v1.2 | Windows 服务模式（UAC 安全桌面可控） | Synergy "Elevate" 同款方案；需提权安装，依赖 T-704 MSI |
| v1.3 | Linux 支持（X11/Wayland） | ms-platform trait 已预留 |
| v2.0 | 公网中继（自建服务器，端到端加密） | 超出局域网边界，属大版本 |

### C. 低成本高感知的小功能（AI 可直接自主完成，供挑选）

1. **传输速率与历史**：进度面板加 MB/s、剩余时间、最近 N 次传输记录（T-506 遗留的自然延伸）。
2. **连接质量面板增强**：设置窗显示 RTT 曲线/丢包/重连次数（数据源 ConnStatus 已有，只差 UI）。
3. **热键自定义**：目前 Ctrl+Alt+方向硬编码，做成 config.json + 设置界面可改。（3×Esc 逃生已按用户要求移除，T-614）
4. **剪贴板同步白名单/开关细化**：按类型（文本/图片/文件）分别开关，或单次穿越临时禁用。
5. **"演示模式"**：一键锁定不穿越（比暂停轻量，保留连接只锁边缘），适合投屏/游戏场景（边界与限制 §5.5 的正向规避）。
6. **诊断导出**：一键打包两端日志+配置+版本号，方便你回报问题（能显著降低 H-2 往返成本）。

## 3. 执行方式（怎么跑这份清单）

按 CLAUDE.md 既定流程，无需新机制：

1. **决定采纳项**：你从 §1/§2 勾选，AI 把采纳项登记进 TASKS.md（新任务给 T-6xx/T-7xx 编号，注明拆分/新增原因）。
2. **AI 自主推进**：每会话按"进行中→按依赖领待办"领任务；三连门槛（fmt/clippy/test）全绿才标完成；一任务一 commit；OPLOG 记账。
3. **人工只在 H-x 点介入**：本清单里你需要出面的只有四类——
   - **H-3 证书**（第一梯队的最大外部依赖，建议尽早办：Apple Developer ID ¥688/年 + Authenticode 证书）；
   - **H-2 双真机操作**（浸泡 72h、安装包全流程实测）；
   - **H-5 主观体验**（滚轮方向、交还推挤等零散确认，可攒一批一次做）;
   - **H-6/H-7 确认**（建 GitHub 仓库、发布 tag/上传）。
4. **建议的开工顺序**：T-602 收尾（收掉唯一进行中任务）→ T-702 回环浸泡 + T-703 安全验证（纯 AI 可跑）→ 等 H-3 证书期间做小尾巴批次/协议前向兼容 → T-704 安装包 → 双真机 72h → T-706 发布 v1.0 → 开 v1.1（T-508 拖拽传输打头）。
