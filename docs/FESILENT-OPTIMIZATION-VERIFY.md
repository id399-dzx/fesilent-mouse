# Win / Mac 与多设备优化验证

日期：2026-10-19。用户确认Linux暂缓。本批实现范围为建议1–4中的平台可靠性、控制交互、文件/设备体验、Mac可选主控与多设备目标管理。

自动化核对和原生预览不能替代真实双机输入验收。本机运行中的上游MouseShare不替换；候选在本项目dist内。

## 已实现

- 会话接通捕获健康、辅助功能权限、心跳、Mac睡眠/唤醒和屏幕变化检测；遇故障先解除grab、释放所有按键、恢复光标、停止捕获，再结束连接。网络发送有界，剪贴板与文件子任务随会话退出。
- QUIC收包半帧状态保留在流对象中，定时器取消不会丢字节。回归在旧版出现“帧载荷超限”，修复后头部和载荷两种取消均恢复完整消息。
- 临时锁在本机、可设置快捷键、真实控制对象、重试倒计时与首次成功引导。快捷键重复按下不重复切换，进入grab时释放已到本机的快捷键前缀和末键。
- Mac主控显式启用，旧配置保持从属；同时发起控制按证书身份确定唯一控制方。清理顺序和碰撞仲裁有核心/真实QUIC回归。
- 已保存多设备与单一活动目标、名称、方位、偏移和完整指纹。连接身份必须与所选目标一致；无目标时不自动挑选旧设备。自动发现的临时源端口不冒充可保存的监听地址。
- 单设备撤销成功后才从清单移除；失败保留记录供重试。设备操作和退出期间不再启动其他会话。
- 文件独占UUID暂存、原子不覆盖落地、分块id/偏移/总大小/结束与EOF校验、网络等待可取消、任务终止清理；迟到文件不覆盖新文本或用户本机新剪贴板。
- 打包检查统一验证SHA、Windows PE架构/GUI/图标、Mac bundle/ARM64/签名/解包；本机loader仅触发未知参数退出，不启动捕获或网络。

## H-2 / H-5 真机回归

| 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| 首次配对 | 两端运行新候选，核对并批准六位码 | 未批准前无控制；批准后可重复连接 |
| Windows控制Mac | 保持Mac默认接收，配置四向逐一跨屏 | 方位一致，返回不会立即弹回 |
| Mac控制Windows | Mac使用偏好显式允许主控，配置对端方位 | Mac本机键鼠能控制Windows，返回/锁定可随时恢复 |
| 组合键 | 左右Ctrl/Alt/Shift/Command、复制粘贴、长按、快捷键长按 | 无幽灵按键或残留修饰键；快捷键只触发一次 |
| 临时锁定 | 控制对端时点击锁定或按锁定键；对端尝试跨屏 | 两端恢复本机，锁定期间不接收远端进入；解锁后可重试 |
| 断网/暂停/退出 | 按住修饰键时断网或暂停，托盘退出 | 本机恢复输入，对端按键释放；退出等待安全清理 |
| 权限撤销 | 会话中撤销Mac辅助功能权限 | 不再拦截本机输入，有权限指引；重新授权后可连接 |
| 休眠唤醒 | 任一端休眠，唤醒并恢复局域网 | 旧控制结束、可重连，不沿用旧按键状态 |
| 显示变化 | 外接屏插拔、分辨率/缩放/主屏变化 | 安全重建会话，使用新边界，不向旧屏坐标持续注入 |
| 屏幕偏移 | 给目标设置非零沿边偏移，再从共同边/非共同边推入 | 共同边按物理像素映射；非重叠段不会跨屏；0保持比例 |
| 多设备 | 保存A/B，分别设不同方位并选中连接；断网重连 | 每次只有选中身份接收输入，不自动换到其他旧设备 |
| 忘记设备 | 撤销单设备并模拟配置目录不可写 | 成功才移除记录；失败保留可重试；两端配对分别管理 |
| 文件 | 同名、不同扩展、大文件、取消、并行复制新文本 | 原文件不覆盖；取消无暂存；迟到文件保留下载但不抢新剪贴板 |
| UAC/锁屏 | Windows出现安全桌面后返回 | 本批不提供SYSTEM服务；失败明确提示并释放输入，不能宣称支持UAC控制 |

## 当前边界

一个活动会话；没有多路同时控制、原生文件跨屏拖放、目录树传输、断点续传或Linux后端。复制目录须先ZIP。多文件归批仍采用既有2秒窗口；文件落地需要接收文件系统支持hard link，不支持时明确失败以避免覆盖。旧版无标记.ms-part保留，不自动误删。Mac为本地ad-hoc签名，正式证书、公证及Windows原生运行另验；本次不推送或发布。
