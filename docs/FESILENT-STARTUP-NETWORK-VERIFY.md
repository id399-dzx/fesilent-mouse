# 单实例工作台与自动连接地址验收

日期：2026-10-20；候选版本：0.2.2；任务：F-1016（整合F-1017）。

## 交付行为

- 同一用户普通GUI启动只有一个进程/托盘/工作台。再次双击或运行不同目录的副本时，副实例请求恢复已有窗口并退出，不再创建额外的连接服务。
- 已保存设备继续在“我的设备”中添加、选择、命名、设置方位/偏移及解除信任；每次一个活动连接，切换先停止原会话。
- Windows副实例转交前台权限，主窗口恢复最小化并聚焦；Mac Finder/Dock重开通知现有窗口。自动配对/文件确认仍走原有不抢焦点显示行为。
- 主界面直接显示可复制的“本机IPv4:监听端口”，后台每5秒刷新已连接物理网卡，不在绘制线程执行命令。枚举命令4秒超时、消息队列有界；排除回环、断开与虚拟/VPN网卡。
- 裸IP及IP后空冒号自动补53728，并写回输入；合法显式端口保留，非法/零/超限继续报错。
- GUI保留命令行监听端口，自定义55200时地址卡片显示55200，不再丢失该覆盖；拒绝`--port 0`避免随机监听而展示固定端口。

## 实现范围

实例权威为用户应用目录内操作系统独占文件锁；锁与IPC元数据分开，避免Windows独占字节锁阻止读取端口。端口为随机loopback TCP端口，凭据为随机token，限制协议长度与总等待时间。持锁但唤出无响应不会降级另开GUI；崩溃由系统释放锁，旧元数据不能阻止重启。退出开始拒绝激活，副实例有界重试直至旧实例完成清理，避免将重开请求误报成功后吞掉。

headless、回环、录制/回放、自检及隔离预览不进入真实GUI单实例范围；实际main分支与保护判定共用，避免仅跳过锁却仍创建GUI。显式调试多实例不代表多路产品会话。

Mac仅给winit现有delegate补充缺失的重开selector，不替换delegate或其他生命周期方法。Rust最低声明改为1.89以使用安全标准库文件锁，无新增依赖。相应严格Clippy要求的旧嵌套if/分块写法已做等价调整。
